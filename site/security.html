1. Core Security Invariants

ClockLend is built directly in native Solana SBF Rust (solana-program v2.2.1) without heavy frameworks or macro abstractions. The entire settlement pipeline adheres to formal cryptographic invariants:

  • Pure Integer Arithmetic (Float-Free): All interest calculations, LTV ratios, liquidation margins, and dividend distributions use 128-bit integer math with saturating additions and checked multiplications. Zero floating-point arithmetic guarantees 100% deterministic execution and immunity to IEEE-754 precision drift.
  • Fail-Closed AccountKind Discriminators: Every on-chain account incorporates an explicit 8-byte discriminator verified before any instruction unpacks data, completely preventing cross-type confusion attacks.
  • Isolated PDA Escrow Vaults: Collateral and principal never enter omnibus pools. Each loan and pawn offer derives unique Program Derived Addresses (PDAs) with cryptographically validated program authority seeds, preventing unauthorized fund drains.
  • Anti-Frontrunning Pre-Creation Defense: Escrow and vault initialization instructions assert program ownership and strict zero-lamport initialization checks, preventing griefing attacks where malicious actors pre-fund PDAs.
  • Fail-Closed Oracle Staleness Guard: Price feeds older than 600 seconds automatically halt borrow and liquidation operations, protecting users and liquidity providers from flash loan attacks and market dislocations.
  • 24-Hour Social Grace Window: Borrowers past due receive a 24-hour protection window where social peers or community members can rescue the debt before liquidation triggers, stopping automated liquidation bot cascades.

2. Protocol Revenue & Capital Distribution Security

ClockLend's monetization model is non-custodial and enforced directly on-chain:

  • 50% Staker Dividend Stream: Half of all loan origination fees (0.25% SOL / 0.50% USDC/SKR) are split automatically at disbursement and transferred into the SkrYieldVault PDA. Stakers claim proportional USDC dividends anytime with a 1-hour anti-flash-loan harvest cooldown.
  • 100% Principal Protection + 85% Interest for LPs: Lending desk owners maintain isolated custody over their funds. Upon loan repayment, 100% of the loan principal and 85% of accrued interest return to the desk vault PDA.
  • 🔥 30% Protocol Revenue Buy & Burn: 30% of all project revenue is dedicated to buying and burning $SKR tokens (via Jupiter DEX market buys and direct SPL token burns), permanently destroying circulating supply.
  • 70% Protocol Reserves: Kept in the on-chain Treasury PDA for protocol security, insurance reserves, and gas for decentralized keepers.

4. Mobile & Android Seeker Hardware Security

ClockLend was developed specifically for the Solana Seeker hardware ecosystem, leveraging enterprise-grade client protections:

  • Seed Vault Integration: Hardware-backed key generation and BIP-39 seed storage inside the device Secure Processing Unit (SPU). Private keys never touch app memory or JavaScript heap.
  • FLAG_SECURE Screen Shielding: Prevents unauthorized screen captures, screen recording trojans, and operating system task switcher leakage.
  • Anti-Tamper & Anti-Emulator Guard: The mobile application automatically halts execution when running on rooted hardware, emulators, or dynamic instrumentation tools (Frida, Xposed).
  • Zero Remote Server Dependency: The client connects strictly to decentralized Solana RPC and WebSocket nodes. No centralized backend intermediary ever has access to user transactions.
